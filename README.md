# Biddarthi

Developed **Biddarthi**, a centralized university application designed to streamline student life by integrating core campus services into a single, user-friendly platform. Built with a strong emphasis on usability, scalability, and real-time interactivity, Biddarthi enhances productivity, accessibility, and overall student engagement.

## Features

### Real-Time Cafeteria Menus & Meal Pre-ordering  
Students can view up-to-date cafeteria menus and pre-order meals to reduce wait times, helping streamline the on-campus dining experience.

### Bus Route Tracking & Notifications  
Includes a real-time bus tracking system with:
- Live location updates  
- Delay alerts  
- Schedule change notifications  
Improves commuting convenience and reliability.

### Personalized Academic Scheduler  
An intelligent scheduling tool that allows students to:
- Organize class schedules  
- Set assignment deadlines and exam reminders  
- Receive automated alerts for upcoming academic tasks  

### Club & Event Management  
Centralized system to discover and engage with:
- University clubs  
- Campus events  
- RSVP functionality with reminders  
Fosters greater extracurricular participation and time management.

### AI-Powered Communication Hub  
Integrated a smart communication system featuring:
- AI-powered chatbots for answering common student queries  
- Secure messaging between students and faculty  
Enables fast, seamless interaction and access to campus support.

### Emergency Alerts & Lost Item Reporting  
To improve campus safety, the app includes:
- Instant emergency broadcast notifications  
- Lost-and-found item submission and tracking system  

---

**Biddarthi** empowers students by simplifying access to essential university services, encouraging academic success, fostering community engagement, and ensuring a safer, more connected campus environment.

## 🛠️ Tech Stack

- Frontend: React, Next.js, TailwindCSS,
- Backend: Node.js, Express
- Database: MongoDB, Mongoose

## 🚦 Getting Started

### Frontend or client

1.  Clone the repository

```
git clone https://github.com/farhanpavel/Bidyarthi
```

2.  Go to the client folder

```
cd client
```

3.  Install dependencies in the client folder

```
npm install
```

4.  Run the development server in the client folder

```
npm run dev
```

5.  Build for production

```
npm run build
```

6.  Watch it live on your browser in this URL

```
http://localhost:3000
```

### Backend or server

1.  Go to the server folder

```
cd server
```

2.  Install dependencies in the server folder

```
npm install
```

3.  Run the development server in the server folder

```
nodemon app
```

4.  The server is running on

```
http://localhost:4000
```
